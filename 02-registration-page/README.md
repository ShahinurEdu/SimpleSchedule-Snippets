# Step 2: The Create Account Page

**Goal:** Add the "Create an account" screen and link the two pages together.

**Files:** `index.html` (same as Step 1), `register.html` (**new**), `style.css` (same as Step 1)

## Steps

1. **Copy** `index.html` and name the copy `register.html`.
2. **Change the text** to match the prototype: "Create your workspace", "Create an account", "Start sharing your appointment page in minutes."
3. **Add a "Full name" field** above the email. Give it `id="name"`.
4. **Change the button** text to "Create account".
5. **Link back** to sign in: `<a href="index.html">Sign in</a>`.
6. **Reuse the CSS.** Both pages use the same `style.css`. Same classes give the same look, so we write the CSS only once.

## Run it

Open `index.html`, then click **Create one**. Click **Sign in** to go back.

## Try it yourself

- Add a "Confirm password" field.
- Build the **Forgot password** page from the prototype ("Reset your password" with one email field and a "Send reset link" button). Link it from the "Forgot password?" text on the sign in page.
